# Деловой тон

Сайт детейлинг-центра в Екатеринбурге. Услуги: химчистка от 6 000 ₽, полировка от 8 000 ₽, тонировка от 5 000 ₽. Итоговая стоимость уточняется при записи.

Сайт: https://kirill596.github.io/delovoy-ton/

Админка: https://kirill596.github.io/delovoy-ton/admin.html

## Организация

index.html содержит HTML, стили, JavaScript и встроенные изображения. Он работает на GitHub Pages без сборки и внешнего сервера. admin.html открывает административный интерфейс. Для редактирования измените исходный код index.html.

Админка демонстрационная, без защиты паролем. Каталог хранится только в localStorage текущего браузера: изменения не синхронизируются между устройствами и не изменяют опубликованный код. Товары в начальном каталоге демонстрационные. Платежи и отправка заявок не подключены; запись ведёт в Instagram.

Фото и макеты услуг предоставлены владельцем проекта. Отзывы, точный адрес и телефон ожидают подтверждения. Секретов и учётных данных в проекте нет.
